기도 인증 현황 — 기존 사용자 새 버전 설치 안내 (v1.0.0을 쓰고 계신 분)
=====================================================================

이번 새 버전부터는 프로그램 안의 [업데이트] 버튼으로 새 버전을 받을 수 있습니다.
지금 쓰시는 v1.0.0에는 이 버튼이 없어서, 이번 한 번만 아래 순서대로 직접 바꿔 주세요.
순서대로 하면 지금까지의 기록(참여자 설정, 검토 판정, 수동 기록, 올린 대화)이 그대로 이어집니다.

■ 준비물
  - 새 버전 압축 파일 (기도인증현황_v1.0.x.zip)
  - 지금 쓰고 있는 프로그램 폴더 (run.bat 이 들어 있는 폴더, 이하 "기존 폴더")


■ 1단계. 프로그램 닫기
  브라우저의 프로그램 탭과 검은 창을 모두 닫습니다.
  ※ 프로그램이 켜진 상태에서 복사하면 기록이 덜 복사될 수 있습니다.


■ 2단계. 기록 백업하기 (꼭 해 주세요)
  1. 기존 폴더를 열면 data 라는 폴더가 있습니다.
  2. data 폴더 안에 prayer_tracker.db 파일이 있는지 확인합니다.
     (이 파일 하나에 모든 기록이 들어 있습니다)
  3. data 폴더를 통째로 복사해서 바탕 화면에 붙여 넣고,
     이름을 "기도인증 백업_오늘날짜"처럼 바꿔 둡니다.
  ※ 이 백업은 새 버전이 잘 동작하는 것을 확인한 뒤에도 한동안 지우지 마세요.


■ 3단계. 새 버전 압축 풀기
  1. 새 버전 압축 파일을 기존 폴더와 "다른 곳"에 압축 풀기 합니다.
     (예: 바탕 화면에 풀기 → "기도인증현황" 폴더가 새로 생김)
  2. 기존 폴더 위에 덮어서 풀지 마세요.
     ※ 같은 곳에 풀어서 이름이 겹치면, 새 폴더 이름을 "기도인증현황_새버전"처럼 바꿔 주세요.
  이하 새로 푼 폴더를 "새 폴더"라고 부릅니다.


■ 4단계. 기록을 새 폴더로 옮기기
  1. 기존 폴더의 data 폴더를 열고, 안에 있는 파일을 "모두" 선택해서(Ctrl + A) 복사합니다(Ctrl + C).
  2. 새 폴더의 data 폴더를 열고 붙여 넣습니다(Ctrl + V).
  3. "같은 이름의 파일이 있습니다" 창이 뜨면 [대상 폴더의 파일 덮어쓰기]를 누릅니다.
     (새 폴더의 data 폴더에는 안내 문서 한 개만 들어 있어서, 덮어써도 괜찮습니다)
  4. 새 폴더\data 안에 prayer_tracker.db 가 있는지 다시 확인합니다.


■ 5단계. 새 버전 실행하기
  1. 새 폴더의 run.bat 을 더블클릭합니다.
  2. 새 폴더라서 처음 실행 준비를 한 번 더 합니다. (인터넷 필요, 3~10분)
     "Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] → [실행]을 누릅니다.
  3. 프로그램이 열리면 아래를 확인합니다.
     - 왼쪽 위 "버전"이 새 버전 번호(1.0.1 이상)인지
     - 대시보드에 지금까지의 기록이 그대로 보이는지
     - 참여자 설정의 대상자 10명, 검토에서 정한 판정이 그대로인지
     - 왼쪽 메뉴 맨 아래에 "업데이트"가 있는지


■ 6단계. 정리 (모두 확인한 뒤에만)
  - 기존 폴더는 지워도 됩니다. 2단계에서 만든 백업은 한동안 남겨 두세요.
  - 바탕 화면에 기존 run.bat 바로 가기를 만들어 두셨다면, 새 폴더의 run.bat 으로 다시 만들어 주세요.


■ 기록이 보이지 않으면
  1. 프로그램(브라우저 탭과 검은 창)을 닫습니다.
  2. 새 폴더\data 안에 prayer_tracker.db 가 있는지 확인합니다.
     없으면 4단계를 다시 합니다. (기존 폴더나 2단계 백업에서 복사)
  3. run.bat 을 다시 실행합니다.
  그래도 안 되면 프로그램을 더 만지지 말고 관리자에게 연락해 주세요.
  기존 폴더와 2단계 백업이 있으면 기록은 언제든 되살릴 수 있습니다.


■ 다음부터는
  새 버전이 나오면 프로그램 화면 왼쪽에 "새 버전이 있습니다"와 [업데이트] 버튼이 나타납니다.
  1. [업데이트]를 누르면 새 버전을 내려받아 준비합니다.
  2. "업데이트 준비를 마쳤습니다"가 나오면 브라우저 탭과 검은 창을 닫고 run.bat 을 다시 실행합니다.
  이때는 기록을 옮길 필요가 없습니다. 업데이트는 프로그램 파일만 바꾸고 data 폴더는 그대로 둡니다.
  적용 직전에는 data\backup 폴더에 기록 사본이 자동으로 하나 더 저장됩니다.
