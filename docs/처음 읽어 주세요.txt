기도 인증 현황 — 처음 읽어 주세요
=====================================

■ 실행 방법
  1. 이 압축 파일을 원하는 곳(예: 바탕 화면)에 "압축 풀기" 합니다.
     ※ 압축 파일 안에서 바로 실행하지 말고, 꼭 압축을 푼 뒤 실행하세요.
  2. 압축을 푼 폴더에서 run.bat 을 더블클릭합니다.
  3. 처음 한 번은 준비 작업이 진행됩니다. (인터넷 필요, 3~10분)
     검은 창에 진행 상황이 표시되니 끝날 때까지 기다려 주세요.
  4. 준비가 끝나면 인터넷 브라우저에 프로그램 화면이 자동으로 열립니다.
     다음부터는 run.bat 을 더블클릭하면 바로 열립니다.

■ "Windows의 PC 보호" 파란 창이 뜨면
  인터넷에서 받은 파일이라 Windows가 확인을 요청하는 것입니다.
  [추가 정보] → [실행]을 누르면 됩니다.

■ 사용을 마칠 때
  브라우저 탭과 검은 창을 닫으면 됩니다.
  검은 창을 닫으면 프로그램이 종료되니, 사용하는 동안에는 최소화만 해 두세요.
  기록은 자동으로 저장되어 다음에 실행해도 그대로 남아 있습니다.

■ 자세한 사용법
  같은 폴더의 「사용방법.pdf」를 열어 보세요.

■ 내 기록은 어디에 저장되나요?
  이 폴더 안의 data 폴더(prayer_tracker.db)에만 저장되고, 인터넷으로 보내지지 않습니다.
  - 백업: data 폴더를 통째로 복사해 두세요.
  - 업데이트로 기록이 바뀌거나 지워지지 않습니다. 업데이트를 적용하기 직전에
    data\backup 폴더에 기록 사본이 자동으로 하나 더 저장됩니다.

■ 새 버전으로 업데이트
  새 버전이 나오면 프로그램 화면 왼쪽에 "새 버전이 있습니다"와 [업데이트] 버튼이 보입니다.
  1. [업데이트] 버튼을 누르면 새 버전을 내려받아 준비합니다.
  2. "업데이트 준비를 마쳤습니다"가 나오면 브라우저 탭과 검은 창을 닫습니다.
  3. run.bat 을 다시 더블클릭하면 새 버전이 적용된 뒤 프로그램이 열립니다.
  ※ 업데이트는 프로그램 파일만 바꾸고, data 폴더(기록)는 그대로 둡니다.
  ※ 적용에 실패하면 원래대로 되돌리고 이전 버전으로 실행합니다.

■ 문제가 생기면
  - 인터넷 연결을 확인하고 run.bat 을 다시 실행해 보세요.
  - 그래도 안 되면 검은 창의 [문제가 생겼습니다] 아래에 표시된 설치 폴더를 지우고 다시 실행해 보세요.
    (보통 이 폴더 안의 runtime 폴더입니다. 기록은 지워지지 않습니다)
  - 오류 내용은 그 설치 폴더의 setup.log, server.err.log 에 남습니다.

■ 필요 환경
  Windows 10 또는 11 (64비트), 처음 실행할 때 인터넷 연결.
  따로 설치할 프로그램은 없습니다.
